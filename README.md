# ThinkForge AI

An AI-powered problem-solving tutor that helps students develop logical thinking instead of simply providing answers.

## Features

- Guided hints instead of full solutions
- Multi-level hint generation
- RAG-powered knowledge retrieval
- Time and space complexity analysis
- Personalized feedback
- Algorithm recommendations
- Solution comparison
- Progress tracking

## Tech Stack

Frontend
- React
- Tailwind CSS

Backend
- FastAPI

AI
- LangChain
- FAISS
- Ollama
- Mistral
- Sentence Transformers
